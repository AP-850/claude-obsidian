## The "Transition-in-Place" Model

Core idea: rather than building the MDTC as a net-new cell requiring wholly new billets, identify existing SBTDWS functions whose current output is already conceptually adjacent to a function the MDTC needs, and evolve that function — and its staff — in place.

> [!key-insight] This already matches existing, endorsed internal analysis — confirmed 2026-08-08
> [[ADWC Three Wing Structure]] (ingested 2026-05-26) already maps this exact transition: Collective Training Wing → CTVMR Wing (main effort), E&E Wing → CTVMR Wing (OC/T and validation, "retrain as OT cadre; phase out FST; SAG 9/10 validation authority"), CAPDEV Cell → TEIW. Workstream 1 is not proposing new wing architecture — it's reconfirming already-built analysis and adding the staffing-numbers layer (below) and the COA 2 / Mwaisena forecasting problem (below) that the original analysis didn't carry.

### Case 1 — Collective Training Wing → CTVMR / MDTC framework development

- **Current state:** runs "vanilla," company-level collective training that doesn't genuinely test or validate companies. Low rigor, but the wing has already developed strong frameworks and concepts for what more rigorous collective training could look like — consistent with [[SBTDWS Overview]]'s existing assessment that this wing is "already running battle-lab-style exercises."
- **Proposed transition:** wind down the current low-value training delivery. The wing continues running some company collective training in the interim, but progressively applies its own new concepts as they're developed — the wing's job evolves from "run vanilla training" to "build and run the MDTC framework," using the same people.
- **Cost:** an accepted drop in capability — units stop getting the current company-level collective training package during the transition.

### Case 2 — Foundation Skills Test (FST) → transitions out to units; E&E Wing core team → OT cadre

- **Current state:** FST is run by a core E&E Wing team plus assessors attached from the units themselves (attachment tour ~1–2 years) whose own unit's sub-units come down to be tested. Results are handed back to the unit quickly. **Scope confirmed 2026-08-08: squad/section level only, no company-level extension** — consistent with [[SBTDWS Overview]]'s existing record.
- **Confirmed 2026-08-08: the FST function itself transitions OUT to the units, not into the MDTC.** Per the user: this isn't SBTDWS's decision to make — J7 will present it — but it's assessed as the doctrinally correct move: section/sub-unit-level assessment should happen at the unit, not be centralised at the school. This is expected to free a significant amount of capacity.
- **The core E&E Wing team's skills — not the FST function itself — become the seed for the OT cadre** and the broader validation/mission-rehearsal function the MDTC needs. Consistent with [[SBTDWS Overview]]'s existing recommendation and directly consistent with the already-endorsed [[J7 Readiness Flow and Deliverables Register]] 8-stage model, where individual/unit-level readiness sits with the unit and SBT's OT function operates at the collective/formation/SAG-validation tier — this proposal is a concrete staffing mechanism for a readiness flow J7 has already endorsed. See [[OC-T Cadre Development Plan]] for the existing OT pipeline design this feeds.

> [!note] These two wings only get partway there
> Per the user directly: "we're gonna need expertise we might not necessarily have that expertise now." Transition-in-place identifies who *can* evolve into part of the answer using existing headcount — it does not close the full expertise gap. See the Moasana section below for how the remaining gap gets sized and requested.

### Case 3 (tentative) — Individual Skills Wing → protected core runner

Per the user, 2026-08-08, explicitly flagged as **"only a thought, not set in stone"**: with Collective Training Wing pivoting toward CTVMR/MDTC framework development and E&E Wing pivoting toward the OT cadre, the third wing — **Individual Skills Wing** — could arguably become the wing that runs the remainder of courses and training that stay as the permanent COA 2 protected core (see Course Consolidation below). Not proposed as a decision; recorded as a candidate answer to the "what forms the protected core" question, worth carrying into the next working session rather than treating as settled.

> [!key-insight] Clarified 2026-08-08: desert warfare identity persists regardless of which COA wins
> This case describes what happens to Individual Skills Wing *as a dedicated course-delivery wing* under COA 2 specifically. Per the user directly: SBTDWS remains the PG's centre of excellence for desert warfare under **either** COA — same training area, same accumulated expertise, same people. Even under COA 1, where the formal wing winds down, the organisation doesn't stop being desert warfare specialists; it delivers that expertise differently. See [[Workstream 4 — Task 1 Deep Dive (COA Overlays)]] and [[SBTDWS Core Focus — Decision Brief (Two COAs, Revised)]] for the full correction — earlier language across this workstream read as if COA 1 meant losing desert warfare identity, which was an oversight, not the intent.

## Moasana — The OOB Bureaucracy Constraint (new, 2026-08-08)

**Moasana** (canonical spelling, confirmed 2026-08-08; earlier captured in this workstream as "Mwaisena," an alternate transliteration of the same term) is the PG/MOD order of battle system — personnel, equipment, resources, and everything attached to formal establishment. This is the single sharpest new constraint surfaced in this session.

**The constraint:** any change to Moasana goes through an extremely bureaucratic MOD process — in some cases **up to two years** from request to effect.

**The consequence:** SBTDWS cannot afford to request manpower incrementally as needs become clear. It has to **forecast its staffing requirement out to 2030 now**, because a request made when the need is already obvious will land roughly two years too late.

**The political risk:** MOD decision-makers see every PG unit's manpower request side by side. An illustrative example from the user — not a real estimate: if SBTDWS asked for, say, 50 new billets without a strong internal-efficiency case, it risks being read as excessive next to other units' asks (one unit's 20, another's 100) and simply gets pushed back, regardless of whether 50 is actually the right number.

**The strategic reframe:** rather than leading with a single fixed headcount bid, request **delegated flexibility and prioritisation authority** — the ability for SBTDWS to identify and reprioritise its own priority positions as the organisation grows, within an envelope, rather than needing a fresh multi-year MOD cycle every time the picture changes. Final resourcing decisions still go up the chain, but the framing is: "here's what we can do internally with the right authority to prioritise, here's what we still need externally" — not just "give us N people."

**What this requires from Workstream 1:**
1. A named list of priority positions (not a single number) — tied to the transition-in-place model above.
2. A clear line between what's coverable through internal reallocation (Collective Training Wing, E&E Wing transitions) and what's a genuine external gap.
3. A credible, evidenced internal-efficiency case built *before* engaging J1 — per the user: "we need to be clever about how we approach this... showcase that we're being smart... but also need in return some flexibility."

See the Priority-Position Methodology section below for the process that produces this.

## Manpower Philosophy — Internal-First

Explicit sequencing principle from the user: **exhaust internal efficiencies and internal reallocation before requesting external manpower.** An external manpower bid is expected eventually and is not ruled out — but demonstrating genuine, novel internal-first thinking (least organisational disruption, most early benefit) strengthens that case when it comes, rather than opening with a request for more billets.

- **This is fundamentally a J1 (personnel) function to solve** — but SBTDWS should arrive with a credible internal-efficiency case already built, not hand J1 a blank problem.
- **Competing demand:** PG 2030 units are simultaneously growing their own capability under the same transformation and will need their own personnel for it — SBTDWS is not the only claimant on the same skilled-manpower pool. Worth surfacing as a genuine cross-organisational resourcing dynamic, not an SBTDWS-internal planning detail.

## Priority-Position Methodology (2026-08-08)

A repeatable process for turning the transition-in-place model above into the named position list Moasana forecasting requires — not a single headcount number.

**Step 1 — Start from what the MDTC must be able to do, not from current establishment.** Use the CTVMR "three non-negotiable pillars" already defined in [[ADWC Three Wing Structure]] (OPFOR, OC/T cadre, AAR process) plus Mission Rehearsal's named requirements (EXCON/HICON, scenario design cell) as the target function list. This avoids anchoring on today's org chart.

**Step 2 — Map each target function to a source: internal transition, internal gap, or external gap.**

| Target function | Source | Basis |
|---|---|---|
| Collective training framework development | Internal transition | Collective Training Wing, Case 1 above |
| OT cadre (validation, certify/fail/remediate) | Internal transition | E&E Wing core team, Case 2 above — already flagged elsewhere as **the single most time-critical staffing decision**, needed at PREP phase to reach OT cadre IOC by Q2 27 |
| Protected-core course delivery | Internal transition (tentative) | Individual Skills Wing, Case 3 above — not yet confirmed |
| TEIW execution floor (~5–6 posts) | Internal transition | CAPDEV Cell, Case 4 above — holds regardless of Monday's outcome |
| CAPDEV/Innovation establishment above the floor | **BLOCKED pending Monday** | Case 4 above — do not commit until [[PG Innovation Governance Framework (Deep Dive)]]'s meeting lands |
| OPFOR / EXCON / HICON | **Not in place, but already tracked — SBTDWS's task is to prepare an internal estimate, not identify an owner** | Confirmed 2026-08-08: [[J7 Readiness Flow and Deliverables Register]] already carries named instruments — **G1** (EXCON/Instructor/OT Establishment Requirement, target **Oct-26**, jointly owned **COMD PG/J7/COMD SBT**), **G4** (OT and EXCON Cadre Generation and Sustainment Plan, COMD J7, Q1-27), **C8** (Exercise Control/HICON Standard, COMD J7, Q2-28). SBTDWS is already a named co-owner of G1. Detailed scoping happens in subsequent J7-partnered working groups, not unilaterally — but SBTDWS needs its own internal estimate of what it thinks it would/could need ready before then, particularly given G1's Oct-26 date. |
| J2 / J3 / J5 / J6 / J8 school-level staff functions | **External gap, already named** | [[SBTDWS Overview]]'s existing "J-Staff Gap" finding — SBTDWS has none of these today; distinct from the wing-transition question entirely |

**Step 3 — Account for the ~90-100 staff not yet mapped.** The ~15–20 "actual instructors" and 6 Western instructors are the only headcount accounted for so far against a total of ~110–120 military staff. Confirmed 2026-08-08: the working expectation is that **the majority of the remaining ~90-100 will eventually map across to positions within whatever the organisation becomes — both the MDTC and the retained core** — not that they're surplus to requirement. The exact mapping (who goes where) is not yet done and still needs the same case-by-case treatment as the wings above; treat "presumptive majority absorption" as the working assumption, not a completed answer.

**Step 4 — Tier by gate.** Rank positions against which COA 2 gate they gate (MLOC Q4 27 / IOC Q4 28 / FOC Q4 30), not by convenience. OT cadre stands out as Tier 1 — it has the longest lead time of any CTVMR pillar per [[ADWC Three Wing Structure]]'s existing Key Finding.

**Step 5 — Separate "ask for people" from "ask for authority."** Every position on the list gets tagged Internal / External. Only the External-tagged list becomes the Moasana submission; the Internal list becomes the evidence base that justifies asking for prioritisation flexibility rather than a single fixed number.
