# ADF Personnel Recovery Framework

Australian Defence Force (ADF) Personnel Recovery (PR) framework — referenced for SERE-B and PR course development at SBTDWS. The ADF model is considered a reference for establishing PR capability at the Desert Warfare School.

Navigation: [[entities/_index]] | [[SAG 9 and SAG 10]]

---

## PR Mission

To recover Isolated Personnel (IP) — military or civilian persons separated from their unit in an operational environment — and return them to friendly control.

---

## C2 Structure

| Level | Role |
|-------|------|
| CJTF / JTFA | PR authority; JTF PR Officer; coordinates Recovery Forces |
| Component Commands | Supporting PR; allocate Recovery Forces as directed |
| Joint Personnel Recovery Centre (JPRC) | Execution node: tracks IPs, tasks Recovery Forces, coordinates with national PR elements |
| Recovery Forces (RF) | Execute the recovery mission (surface, air, maritime) |

---

## Mission Flow (7-Phase)

1. **Report** — IP reports position and status (SERE comms: radio, beacon, visual signals)
2. **Locate** — JPRC locates IP via signals, beacon, survivor radio
3. **Support** — suppression, ISR support, SERE sustainment if required
4. **Recover** — RF extracts the IP
5. **Reintegrate** — IP receives medical, intelligence debrief, return to duty assessment
6. **Report** — lessons captured; IP status reported up command chain

---

## SERE Levels

| Level | Content |
|-------|---------|
| SERE-A | General awareness — all personnel |
| SERE-B | Basic resistance and survival — personnel at risk of capture |
| SERE-C | Advanced resistance — high-risk personnel (aircrew, SOF, senior leaders) |

SBTDWS relevance: SERE-B is a directed task for IW-qualified personnel. The ADF framework provides the reference model for designing the SBTDWS PR / SERE-B training pipeline.

---

## Quick Reaction Force (QRF)

A designated PR QRF maintains readiness to execute recovery within defined response times. In the ADF model:
- QRF allocated to JPRC
- Rotation model ensures continuous readiness
- QRF includes aviation, ground element, and tactical SIGINT as required

---

## Relevance to SBTDWS / SAG 9

SAG 9 (Combined Unconventional Warfare) includes irregular warfare tasks that bring PR and SERE requirements. SBTDWS must be able to support:
- Individual SERE-B qualification (through IW training pipeline)
- PR planning training for commanders
- Integration of PR into collective training scenarios (EXCON injects)

The ADF model provides a mature, doctrinal framework for adaptation.
