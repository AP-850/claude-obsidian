### Deliverable (Phase 1): `SBTDWS_PM_Framework.html`
- 6 pre-populated LOEs, 42 tasks
- Inline editing, auto-save to localStorage
- Add/remove LOEs and tasks
- Dashboard: live counts, progress %, in-progress, at-risk, complete
- Export/Import JSON
- Print/PDF support

### Phase 2 — Architecture Review

After reviewing phase 1, identified 5 mistakes and rebuilt from scratch:
1. Built UI before data model → Schema-first approach
2. One-file architecture → Modular architecture
3. Visuals retrofitted → Visuals designed with data from day one
4. Single-user assumption → Data on OneDrive, dashboard as viewer
5. No backup strategy → Auto-backup on every change

### Recommended Architecture (Option E: Hybrid)
- Live PM data in SharePoint Lists or Excel on OneDrive (multi-user, audited, backed up)
- Small HTML/PDF generator reads data and produces Commander briefing and Gantt
- HTML becomes the *briefing artifact*, not the *PM system*

### Final Deliverables

**`SBTDWS_PM_Master.xlsx`** — System of record (9 sheets): README, Project, Dashboard, LOEs, Tasks, Gates, Risks, People, History. Pre-populated with 6 LOEs and 41 tasks. Status, Phase and Due Quarter with validated dropdowns. Dashboard sheet with live formulas.

**`SBTDWS_PM_Dashboard.html`** — Briefing viewer. Click "From Excel (.xlsx)" to load workbook. Renders KPI cards, progress donuts (Chart.js), status breakdown, LOE-progress bar chart, full Gantt timeline. Bilingual EN/AR toggle. Print to PDF for Commander brief.

**`SBTDWS_PM_System_Guide.docx`** — Operations guide: cadence (weekly/monthly/quarterly/annual), roles (Sponsor, Secretariat, LOE Leads, WG Chairs), how each workbook sheet works, how to use the dashboard, storage and backup, Claude model selection, first-30-days checklist, risks to the framework.

### Model Selection Guide
- **Opus 4.6** — Strategic work: gap analysis, LOE design, risk identification, blind-spot reviews, multi-source synthesis
- **Sonnet 4.6** — Workhorse: WG charters, status reports, RACI matrices, EN/AR translation, brief drafting, ideation
- **Haiku 4.5** — Fast/cheap/mechanical: bulk classification, action-item extraction, routine summaries, doc reformatting

### Fix Applied (XLSX Error)
CDN dependency issue (SheetJS XLSX is not defined when offline). Rebuilt dashboard as fully self-contained — pure SVG charts, no Chart.js or SheetJS, no internet required. Added `refresh_dashboard.py` script to read Excel and update dashboard HTML. Workflow: (1) update Excel → (2) run `python refresh_dashboard.py` → (3) open dashboard.
