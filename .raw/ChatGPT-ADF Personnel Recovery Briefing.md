# **2. Personnel Recovery Overview**

### **2.1 Definition (ADF / NATO-aligned)**
Personnel Recovery is the **sum of military, diplomatic, and civil efforts** to **prepare for, support, and recover isolated personnel** across the spectrum of conflict and environments.

**Isolated Person (IP)** = any individual (military or authorised civilian) who becomes **separated, dislocated, or otherwise removed** from their unit, **unable to return to friendly control**.

---

# **3. ADF PR Framework**

ADF PR aligns with **NATO PR doctrine (AJP 3.7)**, the **US JP 3-50**, and ADF-specific guidance, focusing on:

- **Preparation** (training, SERE, equipment, plans)
- **Planning** (theatre PR plan, unit PR planning)
- **Execution** (PR Command & Control, OPORDs, QRF employment)
- **Adapted PR** (host nation / coalition-led PR)
- **Reintegration** (medical, psychological, intelligence debrief steps)

ADF PR incorporates the following components:

### **3.1 Five PR Tasks**
1. **Report** (ISR, last known position, notification)
2. **Locate** (sensor-to-shooter ISR fusion, DF, HUMINT)
3. **Support** (CSEL, SATCOM, comms windows, FIRES deconfliction)
4. **Recover** (QRF, air, maritime, SOF, ground)
5. **Reintegrate** (staged reintegration, counter-intel, medical)

# **4. Roles and Responsibilities**

## **4.1 Strategic / Operational Level**
### **Chief of Joint Operations (CJOPS)**
- Overall PR authority in the theatre  
- Approves theatre-level PR guidance  
- Allocates strategic assets (e.g., Air Mobility, Special Operations)

### **Joint Task Force Commander (JTFC)**
- Owns mission-level PR responsibilities  
- Ensures PR is included in OPLAN/CONOPS  
- May appoint **PRCC (Personnel Recovery Coordination Cell)**

### **Personnel Recovery Coordination Cell (PRCC)**
Located within JTF HQ or combined HQ. Responsibilities:
- Produce & maintain **Theatre PR Plan (TPRP)**
- Monitor isolated personnel situations  
- Coordinate assets for PR execution  
- Act as interface with national and coalition partners  
- Synchronise **ISR**, **fires**, **airspace**, and **diplomatic channels**

### **Joint Personnel Recovery Center (JPRC)** – if deployed  
- Higher-end version of PRCC; may be multinational  
- Crisis management for high-risk PR events  
- Provides options to JTFC  
- Maintains PR Common Operating Picture (COP)

ADF uses a layered approach:

- Provide security, sweep, medical stabilisation

- Troop/Squadron/Company-sized element

- **RESCAP** (Rescue Combat Air Patrol) – fixed wing

---

## **6.1 PHASE 1 — REPORT**

### **Immediate Actions**
1. Unit identifies missing/separated personnel

5. PRCC requests latest ISOPREP + mission profile

## **6.2 PHASE 2 — LOCATE**

### **Initial Fixing**
PRCC tasks ISR assets:  
- UAV (EO/IR, WAMI, SIGINT)  
- Direction-finding (DF) assets  
- Coalition ISR  
- HUMINT & civilian reports

### **Authentication Attempt**
- SATCOM/CSEL call  
- PRC-112 challenge/response  
- Visual signalling check  
- Battlefield Geometry analysis (where an IP could realistically be)

**Decision**:  
- **Location Uncertain → Continue ISR**  
- **Location Confirmed → Move to Support Phase**

---

## **6.3 PHASE 3 — SUPPORT**

### **Actions**
- Provide instructions to IP (move, stay put, signal plan)  
- Suppress enemy sensors (EW if applicable)

1. JTFC approves the COA  
2. PRCC tasks QRF / Aviation / SOF

6. Contact with IP  
7. Authentication (ISOPREP challenge)  
8. Medical stabilisation  
9. Extraction via:  
   - Air (rotary)

# **1. PERSONNEL RECOVERY (PR) – FULL SOP (STEP-BY-STEP)**  
**Classification: UNCLAS / Training Use**

---

## **PHASE 1 — REPORT**

### **1.1 Trigger**
- Personnel missing, separated, captured, or unable to return to friendly control.  
- Loss of comms, visual contact, or accountability.  
- Overdue patrol / overdue check-in.  
- Emergency beacon activation (CSEL/PRC-112/etc).

### **1.2 Unit Immediate Actions**
1. Declare **"ISOLATED PERSONNEL" (IP)**.  
2. Initiate **SPOTREP** / ISOLATION REPORT to HQ.  
3. Confirm last-known-position (LKP).  
4. Conduct **quick battlefield geometry assessment**:
   - Threat activity  
   - Terrain/avenues of escape  
   - Friendly proximity  
   - Weather/light  
5. Secure ISOPREP access and pass details to PRCC.

### **1.3 PRCC Actions**
1. Initiate PR Battle Drill.  
2. Notify JTFC.  
3. Activate PR Information Cell.  
4. Begin PR incident log.  
5. Pull ISR feeds for last 2–6 hours.  
6. Alert aviation, SOF, and fires coordination cells.

---

## **PHASE 2 — LOCATE**

### **2.1 ISR Tasking**
- **UAV** (EO/IR/WAMI)  
- **SIGINT / DF**  
- **Fixed wing** ISR  
- **Coalition ISR** if available  
- **HUMINT** (local sources, patrols, partnered forces)

### **2.2 Authentication Attempt**
- CSEL/PRC challenge & response  
- Pre-briefed comms windows  
- Visual signals (panels, IR strobes, hand signals)  
- Identity confirmation questions

### **2.3 Decision Point**
- If location **NOT confirmed** → Maintain ISR, update JTFC.  
- If location **FIXED** → Move to Support Phase.

---

## **PHASE 3 — SUPPORT**

### **3.1 Support Functions**
1. Provide **real-time instructions** to IP.  
2. Establish **Overwatch** (ISR / RESCAP).  
3. Conduct **fires deconfliction** (airspace / artillery).  
4. Issue "hold", "move", or "prepare for recovery" directives to the IP.  
5. Pre-deploy QRF to a staging area.  
6. Build **recovery COAs**:
   - Ground QRF  
   - Aviation lift  
   - SOF recovery  
   - Mixed method  
   - Host-nation assisted  

### **3.2 Planning Output**
- IP location confirmed  
- Threat analysis completed  
- Ingress/egress routes approved  
- Recovery force designated  
- JTFC briefed on risk and COAs  

---

## **PHASE 4 — RECOVER**

### **4.1 Execution Steps**
1. JTFC approves COA.  
2. PRCC issues **Execute Order (EXORD)** to recovery force.
